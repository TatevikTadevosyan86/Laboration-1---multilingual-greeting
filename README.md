# Multilingual Greeting Generator

A simple React application that creates a welcome message based on the user's name and preferred language.


## Features

- Accepts a name as user input
- Lets the user select a preferred language
- Generates a personalised welcome message
- Checks that the user has entered a name
- Supports the following languages:
  - Swedish
  - English
  - Armenian
  - Russian
  - Spanish
  - French
  - German
  - Italian
  - Portuguese
  - Japanese
  - Chinese
  - Arabic

## Technologies

- JavaScript
- React
- HTML
- CSS
- Vite
